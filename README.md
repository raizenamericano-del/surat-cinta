## ✨ Mengapa Aplikasi Ini 1000% SUPER SUPER KEREN?

Aplikasi ini bukan web biasa, melainkan **Full-Stack React (Next.js 14) Web Application** dengan fitur interaktif tingkat tinggi, Easter Eggs eksklusif, dan integrasi API real-time:

### 1. 🔐 NEW: Brankas Rahasia Sinta & Rifki (Secret Keypad & Love Voucher)

- Sinta dan Rifki dapat menulis pesan, balasan maaf, atau ucapan romantis langsung di halaman web.
- Pesan dikirim melalui REST API endpoint **`POST /api/messages`** dan **`GET /api/messages`** sehingga tersimpan real-time di database serverless Vercel.

### 4. ❤️ Live Like Counter API untuk 8 Foto Kenangan (`/api/like`)
- 8 foto kenangan dengan filter tab: **Semua (8)**, **Romantis & Tunangan (3)**, **Nostalgia Masa Kecil (2)**, dan **Kocak & Random / KU TUMBUK KAUU (3)**.

### 5. 💌 Surat Cinta 3D & Minigame Permintaan Maaf (`/api/apology`)
- Amplop bersegel 3D yang bisa dibuka dengan animasi halus.
- Tombol **"Maafin Dong, Rifki! ❤️"**: Meledakkan kembang api & konfeti serta memanggil API `POST /api/apology` untuk mencatat status dimaafkan 100% di server.

### 6. 🎵 Lofi Romantic Audio Synthesizer (Web Audio API) & Pesan Suara

## 🚀 Cara Deploy ke Vercel (Gratis 1 Menit!)

Karena aplikasi ini dibangun menggunakan **Next.js**, deployment ke **Vercel** 100% instan tanpa perlu mengubah build settings:

### Cara 1: Deploy via GitHub (Paling Mudah & Direkomendasikan!)
1. Upload/push seluruh folder proyek ini ke repositori GitHub pribadi/publik kamu.
2. Buka [Vercel Dashboard](https://vercel.com/dashboard) -> klik **"Add New Project"** -> pilih repositori GitHub kamu.
3. Vercel otomatis mengenali ini sebagai **Next.js**. Klik **Deploy**.
4. Dalam ~45 detik, aplikasi Full-Stack kamu (Frontend React + Backend Serverless API) langsung tayang!

### Cara 2: Deploy dari Terminal via Vercel CLI
1. Buka terminal di komputer yang berisi folder proyek ini:
   ```bash
   npm install -g vercel
   vercel --prod
   ```
2. Vercel akan mem-build dan mendeploy aplikasi secara otomatis.
